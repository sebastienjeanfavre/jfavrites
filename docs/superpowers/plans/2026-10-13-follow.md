# Follow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The song view listens to the mic, sends audio chunks to Infomaniak Whisper through a Cloudflare Worker, matches the text to the lyrics, dims sung lines, and scrolls so the current line stays in the upper third of the screen.

**Architecture:** Three new units. `worker/index.js` is a Cloudflare Worker that checks a shared password, forwards one audio chunk to Infomaniak, polls for the result, and returns the text. `js/align.js` is pure matching: lyrics plus cursor plus transcript gives a new cursor. `js/follow.js` owns the mic, the 6 second record loop, the upload pipeline, the cursor, the line classes, and the scroll. The parser learns `{meta: language xx}`, the renderer numbers each line, and `app.js` wires one button.

**Tech Stack:** Vanilla ES modules, no dependencies, `node --test`. Cloudflare Workers deployed with `npx wrangler`. Infomaniak AI Tools, OpenAI-compatible transcription route, async with polling.

**Spec:** `docs/superpowers/specs/2026-10-13-follow-design.md`

## Global Constraints

- **No dependencies in the app or the tests.** Node built-ins only. The worker has none either; `wrangler` runs through `npx` and is not a repo dependency.
- **No build step.** Files served are files written.
- **Song files must be valid ChordPro.** The language uses the standard meta extension: `{meta: language fr}` or `{meta: language en}`.
- **The Infomaniak token never reaches the browser.** It lives only in worker secrets. The browser holds a short shared password in `localStorage` under the key `follow-password`.
- **No DOM access in `align.js` or `chordpro.js`.** They run under `node --test`. `follow.js` and `render.js` may use `document` inside functions, never at module top level.
- **Text content is set via `textContent`, never `innerHTML`.**
- **Tunable constants live in one place each**, exported, with these start values: `CHUNK_MS = 6000` in `follow.js`; `LOOKAHEAD = 60`, `MIN_MATCH = 3`, `MIN_RATIO = 0.4`, `PROMPT_WORDS = 150` in `align.js`.
- **Logging is allowed in `follow.js` only**, one `console.log` per transcript, prefixed `[follow]`.
- **Test lyrics are public domain.** Amazing Grace (Traditional) is the fixture.
- **Target device is iPhone Safari.** Chunks are complete mp4 files from a restarted `MediaRecorder`; a screen wake lock is requested; following stops when the tab is hidden.
- **Node 20 or newer** for `File`, `FormData`, `Request` and `Response` globals in the worker test. The machine runs Node 26.
- **Everything runs from the repo root**, `/Users/sebastienjeanfavre/dev/ideas/JFavrites`.
- **Commits:** conventional with a scope, no attribution trailer.

- [x] **Step 3: Write `js/align.js`**

```js
export const LOOKAHEAD = 60;
export const MIN_MATCH = 3;
export const MIN_RATIO = 0.4;
export const PROMPT_WORDS = 150;

export function normalise(text) {
  return text
    .toLowerCase()
    .normalize('NFD')
    .replace(/[̀-ͯ]/g, '')
    .replace(/[^a-z0-9]+/g, ' ')
    .trim()
    .split(' ')
    .filter(Boolean);
}

export function buildWords(song) {
  const words = [];
  let line = 0;
  for (const section of song.sections) {
    for (const { lyric } of section.lines) {
      for (const word of normalise(lyric)) words.push({ word, line });
      line++;
    }
  }
  return words;
}

export function lyricLines(song) {
  return song.sections.flatMap((section) => section.lines.map((line) => line.lyric));
}

export function currentLine(words, cursor) {
  return words[Math.min(cursor, words.length - 1)].line;
}

export function advance(words, cursor, transcript) {
  const heard = normalise(transcript);
  if (heard.length === 0) return cursor;

  const span = Math.ceil(heard.length * 1.5);
  const end = Math.min(words.length, cursor + LOOKAHEAD);
  let best = { count: 0, last: -1 };
  for (let start = cursor; start < end; start++) {
    const slice = words.slice(start, start + span).map((w) => w.word);
    const { count, last } = lcs(heard, slice);
    if (count > best.count) best = { count, last: start + last };
  }

  if (best.count < MIN_MATCH || best.count < heard.length * MIN_RATIO) return cursor;
  return best.last + 1;
}

export function promptFor(lyrics, line) {
  const out = [];
  let count = 0;
  for (let i = Math.max(0, line - 1); i < lyrics.length && count < PROMPT_WORDS; i++) {
    const text = lyrics[i].trim();
    if (!text) continue;
    out.push(text);
    count += text.split(/\s+/).length;
  }
  return out.join('\n');
}

// Longest common subsequence; `last` is the index in b of the final matched word.
function lcs(a, b) {
  const n = a.length;
  const m = b.length;
  const dp = Array.from({ length: n + 1 }, () => new Array(m + 1).fill(0));
  for (let i = 1; i <= n; i++) {
    for (let j = 1; j <= m; j++) {
      dp[i][j] = a[i - 1] === b[j - 1]
        ? dp[i - 1][j - 1] + 1
        : Math.max(dp[i - 1][j], dp[i][j - 1]);
    }
  }
  let i = n;
  let j = m;
  let last = -1;
  while (i > 0 && j > 0 && last < 0) {
    if (a[i - 1] === b[j - 1]) last = j - 1;
    else if (dp[i - 1][j] >= dp[i][j - 1]) i--;
    else j--;
  }
  return { count: dp[n][m], last };
}
```

- Consumes: Infomaniak `POST /1/ai/{product_id}/openai/audio/transcriptions` returning `{ batch_id }`, and `GET /1/ai/{product_id}/results/{batch_id}` returning `{ status, data }` with status in pending, processing, success, failed, cancelled. Either may be wrapped as `{ result, data: {...} }`.

```js
const API = 'https://api.infomaniak.com/1/ai';
const POLL_LIMIT = 25;
const CORS = {
  'Access-Control-Allow-Origin': '*',
  'Access-Control-Allow-Methods': 'POST, OPTIONS',
  'Access-Control-Allow-Headers': 'Content-Type, X-Password',
};

export default {
  async fetch(request, env) {
    if (request.method === 'OPTIONS') return new Response(null, { status: 204, headers: CORS });
    if (request.method !== 'POST' || new URL(request.url).pathname !== '/transcribe') {
      return reply(404, 'Not found');
    }
    if (request.headers.get('X-Password') !== env.FOLLOW_PASSWORD) return reply(401, 'Wrong password');

    const form = await request.formData();
    const body = new FormData();
    body.set('file', form.get('file'));
    body.set('model', 'whisper');
    body.set('response_format', 'json');
    for (const name of ['language', 'prompt']) {
      if (form.get(name)) body.set(name, form.get(name));
    }

    const base = `${API}/${env.INFOMANIAK_PRODUCT_ID}`;
    const headers = { Authorization: `Bearer ${env.INFOMANIAK_TOKEN}` };
    const created = await fetch(`${base}/openai/audio/transcriptions`, { method: 'POST', headers, body });
    if (!created.ok) return reply(502, 'Infomaniak rejected the audio');
    const batchId = unwrap(await created.json()).batch_id;

    const pollMs = Number(env.POLL_MS ?? 1000);
    for (let i = 0; i < POLL_LIMIT; i++) {
      await new Promise((resolve) => setTimeout(resolve, pollMs));
      const res = await fetch(`${base}/results/${batchId}`, { headers });
      const job = unwrap(await res.json());
      if (job.status === 'success') return reply(200, { text: textOf(job.data) });
      if (job.status === 'failed' || job.status === 'cancelled') return reply(502, 'Transcription failed');
    }
    return reply(502, 'Transcription timed out');
  },
};

// Infomaniak v1 wraps responses as { result, data }; the docs show bare payloads. Accept both.
function unwrap(json) {
  return json.result && json.data !== undefined ? json.data : json;
}

function textOf(data) {
  if (typeof data !== 'string') return data.text ?? '';
  try {
    return JSON.parse(data).text ?? data;
  } catch {
    return data;
  }
}

function reply(status, payload) {
  const body = typeof payload === 'string' ? { error: payload } : payload;
  return new Response(JSON.stringify(body), {
    status,
    headers: { ...CORS, 'Content-Type': 'application/json' },
  });
}
```

- [x] **Step 4: Write `js/follow.js`**

```js
import { buildWords, lyricLines, currentLine, advance, promptFor } from './align.js';

export const CHUNK_MS = 6000;
const WORKER_URL = 'https://jfavrites-follow.REPLACE-ME.workers.dev/transcribe';
const PASSWORD_KEY = 'follow-password';
const FAILURES_TO_STOP = 3;
const MESSAGE_MS = 3000;
const SCROLL_FROM_TOP = 0.3;

let session = null;

export function isFollowing() {
  return session !== null;
}

export async function startFollow(song) {
  const password = localStorage.getItem(PASSWORD_KEY) || prompt('Follow password');
  if (!password) return;
  localStorage.setItem(PASSWORD_KEY, password);

  const words = buildWords(song);
  if (words.length === 0) return;

  let stream;
  try {
    stream = await navigator.mediaDevices.getUserMedia({ audio: true });
  } catch {
    showStatus('Microphone blocked', MESSAGE_MS);
    return;
  }

  session = {
    words,
    lyrics: lyricLines(song),
    language: song.language,
    cursor: 0,
    line: -1,
    failures: 0,
    stream,
    recorder: null,
    timer: 0,
    lock: navigator.wakeLock ? navigator.wakeLock.request('screen').catch(() => null) : Promise.resolve(null),
  };
  document.getElementById('follow').textContent = 'Stop';
  showStatus('Listening');
  document.addEventListener('visibilitychange', onHidden);
  paint(session);
  recordChunk(session);
}

export function stopFollow(message = '') {
  if (!session) return;
  const s = session;
  session = null;
  clearTimeout(s.timer);
  if (s.recorder?.state === 'recording') s.recorder.stop();
  s.stream.getTracks().forEach((track) => track.stop());
  s.lock.then((lock) => lock?.release());
  document.removeEventListener('visibilitychange', onHidden);
  document.getElementById('follow').textContent = 'Follow';
  showStatus(message, MESSAGE_MS);
}

export function repaint() {
  if (session) paint(session);
}

function onHidden() {
  if (document.hidden) stopFollow();
}

// Safari cannot split one recording into standalone files, so each chunk is its own recorder.
function recordChunk(s) {
  const recorder = new MediaRecorder(s.stream);
  const parts = [];
  recorder.ondataavailable = (e) => parts.push(e.data);
  recorder.onstop = () => {
    if (session !== s) return;
    send(s, new Blob(parts, { type: recorder.mimeType }));
    recordChunk(s);
  };
  s.recorder = recorder;
  recorder.start();
  s.timer = setTimeout(() => recorder.stop(), CHUNK_MS);
}

async function send(s, blob) {
  const form = new FormData();
  form.set('file', blob, blob.type.includes('webm') ? 'chunk.webm' : 'chunk.mp4');
  if (s.language) form.set('language', s.language);
  form.set('prompt', promptFor(s.lyrics, currentLine(s.words, s.cursor)));

  let res;
  try {
    res = await fetch(WORKER_URL, {
      method: 'POST',
      headers: { 'X-Password': localStorage.getItem(PASSWORD_KEY) ?? '' },
      body: form,
    });
  } catch {
    failed(s);
    return;
  }
  if (session !== s) return;
  if (res.status === 401) {
    localStorage.removeItem(PASSWORD_KEY);
    stopFollow('Wrong password');
    return;
  }
  if (!res.ok) {
    failed(s);
    return;
  }

  s.failures = 0;
  const { text } = await res.json();
  if (session !== s) return;
  const next = advance(s.words, s.cursor, text);
  console.log(`[follow] "${text}" cursor ${s.cursor} -> ${next}`);
  if (next <= s.cursor) return;
  s.cursor = next;
  paint(s);
  if (currentLine(s.words, s.cursor) === s.words.at(-1).line) stopFollow();
}

function failed(s) {
  if (session !== s) return;
  s.failures++;
  if (s.failures >= FAILURES_TO_STOP) stopFollow('Transcription failed');
}

function paint(s) {
  const line = currentLine(s.words, s.cursor);
  for (const p of document.querySelectorAll('p.line')) {
    const n = Number(p.dataset.line);
    p.classList.toggle('sung', n < line);
    p.classList.toggle('current', n === line);
  }
  if (line === s.line) return;
  s.line = line;
  const el = document.querySelector(`p.line[data-line="${line}"]`);
  scrollTo({
    top: scrollY + el.getBoundingClientRect().top - innerHeight * SCROLL_FROM_TOP,
    behavior: 'smooth',
  });
}

function showStatus(text, ms = 0) {
  const status = document.getElementById('status');
  clearTimeout(showStatus.timer);
  status.textContent = text;
  status.hidden = !text;
  if (text && ms) showStatus.timer = setTimeout(() => showStatus(''), ms);
}
```
